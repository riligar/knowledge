# 📚 Documentation

## 🎯 What is Documentation?

**Documentation** is a revolutionary static documentation generator that transforms your Markdown files into stunning, professional documentation websites. Built for developers who value simplicity without sacrificing power, Documentation eliminates the complexity of traditional documentation tools while delivering enterprise-grade results.

Imagine having the ability to create beautiful, searchable, and responsive documentation in minutes rather than hours. Documentation makes this possible by focusing on what matters most: your content. Write in familiar Markdown, configure with a simple TypeScript file, and deploy anywhere as static files.

## ⚡ Quick Start

Get up and running in under a minute:

```bash
# Install globally
npm install -g @riligar/documentation

# Create new documentation project
documentation init my-docs
cd my-docs

# Start development server
documentation dev
# 🎉 Open http://localhost:3000

# Build for production
documentation build
```
