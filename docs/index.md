# Documentação Principal

Este é o arquivo index.md principal que deve aparecer primeiro na navegação.

## Visão Geral

Esta documentação demonstra como os arquivos `index.md` são priorizados na navegação.

## Estrutura

- **index.md**: Sempre aparece primeiro
- **Outros arquivos**: Em ordem alfabética após o index.md
- **Pastas**: Em ordem alfabética, com seus próprios index.md priorizados
