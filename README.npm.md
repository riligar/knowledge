> A modern, open-source documentation platform that transforms how teams create, organize, and share knowledge.

## 🚀 Quick Start

### Installation

```bash
# Global installation (recommended)
npm install -g @riligar/knowledge

# Or with yarn
yarn global add @riligar/knowledge

# Or with pnpm
pnpm add -g @riligar/knowledge
```

### Usage

```bash
# Create a new documentation project
mkdir my-docs && cd my-docs

# Initialize Knowledge project
knowledge init

# Start development server
knowledge dev

# Build for production
knowledge build

# Serve built site
knowledge serve
```

## ✨ Features

- 🔍 **Instant search** across all content
- 📱 **Responsive design** (mobile + desktop)
- 🌙 **Automatic dark mode**
- 🎨 **Syntax highlighting** for code
- 🧭 **Automatic navigation** based on folders
- 🚀 **Fast build** with modern tooling
- 📦 **Simple deploy** to any hosting
- 🔧 **Zero configuration** required
